.cia（CTR Importable Archive）は、3DS にタイトルをインストールするためのフォーマットです。Nintendo の CDN 上のタイトルと同一のデータ構造を持っており、SDMC または CTR NAND へのインストールが可能です。（3dbrew: http://www.3dbrew.org/wiki/CIA）

今回のポイントは「3DS の httpc で HTTP POST できるか」という点です。3DS の httpc は multipart/form-data に対応しているので、file.io のように curl -F "file=@..." で送れるシンプルな REST API がそのまま使えます。（file.io: https://www.file.io/）

候補を比較するとこうなります：

| サービス | 無料容量 | 有効期限 | APIの簡単さ | アカウント不要 |
| file.io | 100MB/ファイル | 14日（デフォルト）/ 変更可 | ★★★ 最高にシンプル | ✅ |
| tmpfile.link | 100MB | 7日 | ★★★ シンプル | ✅ |
| 0x0.st | 512MB | 〜365日 | ★★★ 超シンプル | ✅ |
| Discord Webhook | 25MB/ファイル | 永続 | ★★ 少し複雑 | ✅（Webhookは公開） |

ズバリおすすめは file.io です。理由が3つあります。

file.io は curl -F "file=@ファイル" https://file.io という1行で使えて、レスポンスとしてダウンロードリンクが JSON で返ってきます。しかも「1回ダウンロードされたら自動削除」という仕組みがあり、スタッフが受け取ったら消える設計になっています。有効期限は ?expires=7d のように URL パラメータで自由に変えられます。（file.io）

つまり 3DS 側でやることは——

ファイルを読む
  ↓
https://file.io に POST（multipart/form-data）
  ↓
レスポンスの JSON からリンクを取り出す
  ↓
そのリンクをスタッフに共有（画面に表示 or Discordに通知）
だけで済みます。

ひとつ気になるのが「スタッフへの通知」の部分です。file.io でリンクが発行されたとして、そのリンクをどうやってスタッフに届けますか？

3DS が送るもの（1回のPOST）
├── file1=リプレイファイル（添付）

      "allowed_mentions": { "roles": ["ロールID"] }
    }

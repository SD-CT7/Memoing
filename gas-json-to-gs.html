GAS JSON → .gs 変換ツール

プロキシ経由で Apps Script プロジェクトを取得し、.gs / .html を ZIP 化します

1. プロキシ経由で取得（推奨）

初回セットアップ（1回だけ）
  1. 下の「プロキシ用GASコードを表示」を開き、コードをコピー
  2. script.google.com で新規プロジェクトを作成し、貼り付けて保存
  3. 関数 forceOAuthScopes_ を一度実行して権限を承認
  4. 「デプロイ」→「新しいデプロイ」→ 種類: ウェブアプリ
  5. 実行ユーザー: 自分 ／ アクセスできるユーザー: 全員（推奨）
  6. 表示されたウェブアプリURLを下の「プロキシURL」に貼る

プロジェクトURL または ID

例: https://script.google.com/home/projects/1Z_jFd0cJ60LwqCm9MEzfcsBqYGpnQqHgdPwnynGIdH9JbPZV8RZtCQMF/edit
